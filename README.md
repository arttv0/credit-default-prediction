# Credit Default Prediction Model (In Progress)

## Objective
Building a machine learning classification model to predict the probability of loan default based on historical financial data. 

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn, XGBoost
* **Visualization:** Matplotlib / Seaborn

## Data Source
Using the [Home Credit Default Risk dataset](https://www.kaggle.com/c/home-credit-default-risk/data) from Kaggle, containing information on client loan applications and payment history.

## Current Status: Phase 1
- [x] Repository initialized and dataset sourced.
- [x] Exploratory Data Analysis (EDA) and handling missing values.
- [x] Feature engineering for categorical variables.
- [ ] Model training (Logistic Regression baseline vs. XGBoost).
